# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| main    | Yes       |

## Reporting a Vulnerability

A Frankstack bundle is a set of instructions that a coding agent follows on your machine, built from
other people's skills, hooks and scripts. Anything that lets a bundle or a catalogue entry make an
agent do something the stack definition does not show is a security issue.

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/hyperlab-sh/frankstack/security/advisories/new) or by
email to me@saulo.engineer. Do not open a public issue.

You can expect an initial response within 48 hours.
